# Confronto C / picca

C e cuore sono gli asset esistenti, senza modifiche. La picca tratteggiata e il glifo U+2660 del font Windows Segoe UI Symbol, usato esclusivamente come riferimento di confronto: non e una maschera da cui fosse stata sottratta matematicamente la C.

C: 78 x 104. Cuore: 88 x 88. Picca: 86.75 x 104. Picca e C allineate per altezza visibile e asse verticale; la picca mantiene le sue proporzioni. Tavola a ingrandimento 4x.
